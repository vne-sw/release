# VNE 프로그램 릴리즈

VNE 프로그램의 릴리즈를 관리하는 저장소입니다. 프로그램 개발에 사용하는 외부모듈도 버전별로 내부 관리합니다.

## 프로그램 릴리즈 관리

프로그램 릴리즈는 프로젝트별 하위 카테고리로 구분하여 관리합니다. 각 프로젝트의 카테고리에서 버전별 릴리즈를 확인할 수 있도록 구성합니다.

## 개발용 외부모듈 관리

개발용 외부모듈은 버전별로 관리하며, 각 프로젝트에서 별도의 배치 파일을 실행하여 필요한 버전을 다운로드하고 프로젝트에 반영합니다.

외부모듈의 상세 목록, 버전 정보 및 다운로드 경로는 내부적으로 관리하며, 이 README에는 공개하지 않습니다.
